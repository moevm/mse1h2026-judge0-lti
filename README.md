# Платформа для решения задач по программированию

## Установка и запуск

### Требования 

- Запуск только на Linux
- Docker
- docker-compose (необязательно, нужен для запуска скрипта start-example.sh)

### Инструкции по установке и запуску проекта.

1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/moevm/mse1h2026-judge0-lti.git
    cd mse1h2026-judge0-lti

2. Создать и заполнить конфигурационные файл .env по примеру .env.example и файл judge0.conf по примеру judge0.conf.example.

3. Запуск впервые
    ```
    chmod +x build-and-run.sh
    ./build-and-run.sh
    ```

    ИЛИ

    ```
    docker-compose up --build -d
    ```

* Для проверки работы проекта предусмотрен упрощённый запуск:
    ```
    ./start-example.sh
    ```

4. Выключение 
    ```
    docker-compose down 
    ```

## Проверка работоспособности
### Инструкция по проверке работоспособности решения Задачи.

1. Установить и запустить проект.

2. Перейти на [курс](https://e.moevm.info/course/view.php?id=190) на платформе e.moevm.info.

3. Перейти на готовый пример модуля.

4. Нажать на кнопку "Начать" и тогда откроется поле для решения задачи.

5. Попробовать решить задание и нажать кнопку "Проверить".

### Инструкция по проверке работоспособности создания новых Задач.

1. Установить и запустить проект.

2. Перейти на [курс](https://e.moevm.info/course/view.php?id=190) на платформе e.moevm.info.

3. Зайти в админ панель через localhost/admin и ввести данные из .env
   Данные по-умолчанию:
   
   Логин: ```admin```
   
   Пароль: ```adminpass```
   

4. В админ панеле можно создавать свои Задачи и Модули. Для создания Задачи нужно перейти в раздел "Задачи" и создать новую. Нужно ввести название задачи, формулировку, можно создавать тесты по одному и загрузить файлом JSON, возможен выбор ограничения по времени и выбор языка программирования.

5. После создания Задачи её нужно добавить в Модуль, Модуль можно создать во вкладке "Модули". Добавить задачу можно перейдя в нужный Модуль, нажать кнопку "Добавить задачу" и выбрать нужную Задачу.

6. Добавить Модуль в [курс](https://e.moevm.info/course/view.php?id=190) на e.moevm.info:
    1. Создать свой элемент курса:
    2. Выбрать judge0-lti-dev, затем заполнить поле "Название элемента курса" и написать в поле "Пользовательские параметры" ```module_id= "Номер модуля в системе"```
